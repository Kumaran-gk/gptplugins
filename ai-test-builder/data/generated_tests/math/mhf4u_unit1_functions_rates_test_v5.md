## Part A - Multiple choice (10 marks)

**1. [1 mark]** Which relation is a function but is **not one-to-one**?

A. `{(0,1),(1,1),(2,3)}`   B. `{(0,1),(0,2),(2,3)}`  
C. `{(0,1),(1,2),(2,3)}`   D. `{(0,0),(1,1),(2,2)}`

**2. [1 mark]** What is the domain of `f(x)=sqrt(2x-6)/(x-5)`?

A. `[3,infinity)`   B. `(3,5) U (5,infinity)`  
C. `[3,5) U (5,infinity)`   D. `(-infinity,3]`

**3. [1 mark]** What is the range of `g(x)=-|x+2|+5`?

A. `[5,infinity)`   B. `(-infinity,5]`   C. `(-infinity,5)`   D. all real numbers

**4. [1 mark]** If `(9,3)` lies on `y=f(x)`, which point lies on `h(x)=-3f(-2(x-4))+2`?

A. `(-1/2,-7)`   B. `(17/2,-7)`   C. `(-1/2,11)`   D. `(4,-7)`

**5. [1 mark]** For `f(x)=(x-1)^2+2` restricted to `x>=1`, what is `f^(-1)(x)`?

A. `1-sqrt(x-2)`   B. `sqrt(x-1)+2`  
C. `1+sqrt(x+2)`   D. `1+sqrt(x-2)`

**6. [1 mark]** Which function is odd?

A. `x^4-4`   B. `x^3-4x`   C. `x^3+4`   D. `x^2+x`

**7. [1 mark]** Let `p(x)=3x-1` for `x<2` and `p(x)=kx+1` for `x>=2`. For which value of `k` is `p` continuous at `x=2`?

A. 1   B. `3/2`   C. 2   D. 3

**8. [1 mark]** What is the average rate of change of `f(x)=x^2-4x` on `[1,3]`?

A. 0   B. 2   C. -2   D. 4

**9. [1 mark]** The centred estimate of the instantaneous rate of `h(t)=-t^2+6t` at `t=2`, using `[1.9,2.1]`, is:

A. 0   B. 1   C. 4   D. 2

**10. [1 mark]** A secant from `x=a` to `x=b` has negative slope, while the tangent at `x=a` has slope 0. Which statement follows?

## Part B - Multipart questions (50 marks)

**11. Piecewise functions [9 marks]**  
The function `F` is defined by

```text
         -(x+1)^2+4   if -3 <= x < 0
F(x) =    2x+3        if 0 <= x <= 2
          9-2x        if 2 < x <= 5
```

a. Sketch `F` on one set of axes. Label the vertex and all open and closed endpoints. [K2 C2]  
b. State its domain and range in interval notation. [K2]  
c. State the intervals where `F` is increasing. [K1]  
d. Would the inverse relation be a function? Explain with one output that occurs for two different inputs. [T1 C1]

**12. Absolute value graph [6 marks]**  
Sketch `g(x)=-3|x+1|+6`. Label the vertex, both x-intercepts, and the y-intercept. [K2 C1] State the domain and range in interval notation. [K2] Explain how the coefficient `-3` changes the graph of `y=|x|`. [T1]

**13. Transforming a function [5 marks]**  
The point `(9,3)` lies on `y=f(x)`, where `f(x)=sqrt(x)`. Define `h(x)=-3f(-2(x-4))+2`.

a. Find the corresponding point on `h`, showing the input equation. [T2]  
b. State the domain and range of `h`. [K2]  
c. Describe the horizontal transformation. [C1]

**14. Inverse relations [5 marks]**  
Let `q(x)=-2(x-2)^2+7`, initially with domain all real numbers.

a. State the domain and range of its inverse relation. [K2]  
b. Explain why this inverse relation is not a function. [T1]  
c. Restrict the domain of `q` so that its inverse becomes a function, then write that inverse function and its domain. [A2]

**16. Average and instantaneous rates [8 marks]**

c. At what time does the ball reach its maximum modelled height, and what is that height? [K2]  
d. Explain why your answers in a and b differ. [C1]
