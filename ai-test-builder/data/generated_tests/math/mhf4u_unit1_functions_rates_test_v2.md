**1. Piecewise functions [9 marks]**  
The function `P` is defined by

```text
         x + 3       if -4 <= x < 0
P(x) =   3 - x^2     if 0 <= x <= 2
         x - 1       if 2 < x <= 4
```

a. Sketch `P` on one set of axes. Label all open and closed endpoints. [K2 C2]  
b. State its domain and range in interval notation. [K2]  
c. State the intervals where `P` is increasing. [K1]  
d. Would the inverse relation be a function? Explain using your graph. [T1 C1]

**3. Transforming a function [5 marks]**

a. Find the corresponding point on `g`, showing the input equation. [T2]  
b. State the domain and range of `g`. [K2]  
c. Describe the horizontal transformation. [C1]

**6. Average and instantaneous rates [8 marks]**

c. At what time does the ball reach its maximum modelled height, and what is that height? [K2]  
d. Explain why your answers in a and b differ. [C1]
