## Part B - Multipart questions (50 marks)

**11. Piecewise functions [9 marks]**  
The function `T` is defined by

```text
         x + 4       if -4 <= x < 0
T(x) =   4 - 2x      if 0 <= x <= 2
         x - 4       if 2 < x <= 5
```

a. Sketch `T` on one set of axes. Label all open and closed endpoints. [K2 C2]  
b. State its domain and range in interval notation. [K2]  
c. State the intervals where `T` is increasing. [K1]  
d. Would the inverse relation be a function? Explain using your graph. [T1 C1]

**12. Absolute value graph [6 marks]**  
Sketch `g(x) = -2|x - 1| + 6`. Label the vertex and both x-intercepts. [K2 C1] State the domain and range in interval notation. [K2] Explain how the coefficient `-2` changes the graph of `y=|x|`. [T1]

**13. Transforming a function [5 marks]**  
The point `(16,4)` lies on `y=f(x)`, where `f(x)=sqrt(x)`. Define `h(x)=2f(-4(x-3))+1`.

a. Find the corresponding point on `h`, showing the input equation. [T2]  
b. State the domain and range of `h`. [K2]  
c. Describe the horizontal transformation. [C1]

**14. Inverse relations [5 marks]**  
Let `q(x)=(x+1)^2+3`, initially with domain all real numbers.

a. State the domain and range of its inverse relation. [K2]  
b. Explain why this inverse relation is not a function. [T1]  
c. Restrict the domain of `q` so that its inverse becomes a function, then write that inverse function. [A2]

**15. Circular ride diagram [7 marks]**

[[WHEEL_DIAGRAM]]

d. Sketch a qualitative height-versus-time graph for one rotation. Label the height at `t=0`, `t=180`, and `t=360`. [C2]

**16. Average and instantaneous rates [8 marks]**  
During its first 8 seconds, a ball's height above the ground is modelled by `H(t)=-2t^2+16t+3` metres.

a. Calculate the average rate of change of height over `[0,2]`. [A2]  
b. Estimate the instantaneous rate at `t=2` using the centred interval `[1.9,2.1]`. Show the two heights used. [A2 T1]  
c. At what time does the ball reach its maximum modelled height, and what is that height? [K2]  
d. Explain why your answers in a and b differ. [C1]

b. If `(2,28)` lies on its graph, use symmetry to name one more point. [K1]  
c. Write the solution to `|x-3|<=2` in interval notation. [K2]
