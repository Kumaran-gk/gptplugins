## How To Use This Guide

Use this as a print-ready final exam review package. Complete the topic checklist first, then try the practice test without notes. Mark your work using the answer key and redo any question where your reasoning was incomplete, even if the final answer was correct.

## High-Yield Topic Checklist

- Chemical naming: acids, ionic compounds, polyatomic ions, and hydrates.
- Mole calculations: molar mass, mass-to-moles, particles-to-moles, and limiting reagents.
- Stoichiometry: balanced equations, theoretical yield, actual yield, and percent yield.
- Solutions: dissociation, concentration, dilution, saturation, solubility, and precipitation.
- Net ionic equations: spectator ions, precipitates, and single displacement reactions.
- Acids and bases: pH, strong versus weak acids, neutralization, titration vocabulary, and indicators.
- Gases: pressure, volume, temperature, Boyle's law, Charles's law, and kinetic molecular theory.
- Water treatment: primary treatment, secondary treatment, filtration, disinfection, and common pollutants.

## Formula And Reference Sheet

- n = m / M
- m = nM
- C = n / V
- n = CV
- C1V1 = C2V2
- percent yield = actual yield / theoretical yield x 100%
- Boyle's law: P1V1 = P2V2 at constant temperature
- Charles's law: V1 / T1 = V2 / T2, where temperature is in kelvin
- 0 degrees C = 273 K
- A saturated solution contains the maximum amount of dissolved solute at a stated temperature.
- A precipitate forms when ions combine to produce an insoluble compound.

26. K2SO4 = 2(39.10) + 32.07 + 4(16.00) = 174.27 g/mol.

27. n = 18.0 g / 18.02 g/mol = 0.999 mol, which is about 1.00 mol.

28. C3H8 + 5O2 -> 3CO2 + 4H2O.

29. C = n / V = 0.300 mol / 0.750 L = 0.400 mol/L.

30. C1V1 = C2V2. (1.50)(200 mL) = (0.500)(V2), so V2 = 600 mL. Water added = 600 mL - 200 mL = 400 mL.

31. Total ionic: Ag+(aq) + NO3-(aq) + Na+(aq) + Cl-(aq) -> AgCl(s) + Na+(aq) + NO3-(aq). Net ionic: Ag+(aq) + Cl-(aq) -> AgCl(s).

32. At saturation, the solution holds the maximum dissolved amount at that temperature. Extra solute remains undissolved because the dissolving and crystallizing processes are balanced.

33. P1V1 = P2V2. (100 kPa)(3.00 L) = (150 kPa)(V2), so V2 = 2.00 L.

34. HCl + NaOH -> NaCl + H2O. n NaOH = (0.100 mol/L)(0.01860 L) = 0.001860 mol. The mole ratio is 1:1, so n HCl = 0.001860 mol. C HCl = 0.001860 mol / 0.02500 L = 0.0744 mol/L.

35. Strong acids ionize almost completely in water; weak acids ionize only partially. At the same concentration, strong acids usually produce higher hydronium concentration, lower pH, and greater conductivity.

36. Moles Al = 5.40 g / 26.98 g/mol = 0.200 mol. Moles Cl2 = 20.0 g / 70.90 g/mol = 0.282 mol. For 0.200 mol Al, required Cl2 = 0.300 mol, so Cl2 is limiting. Moles AlCl3 = 0.282 mol Cl2 x 2 mol AlCl3 / 3 mol Cl2 = 0.188 mol. Mass AlCl3 = 0.188 mol x 133.33 g/mol = 25.1 g. Percent yield = 22.5 g / 25.1 g x 100% = 89.6%.

37. BaSO4 precipitates because sulfates are generally soluble except with Ba2+, Pb2+, Sr2+, and Ca2+ to varying degrees. Net ionic: Ba2+(aq) + SO4 2-(aq) -> BaSO4(s). Moles Ba2+ = 0.0500 L x 0.200 mol/L = 0.0100 mol. Moles SO4 2- = 0.0500 L x 0.200 mol/L = 0.0100 mol. Expected precipitate = 0.0100 mol BaSO4.

38. Convert temperatures to kelvin: T1 = 295 K and T2 = 333 K. V2 = V1T2 / T1 = 45.0 mL x 333 K / 295 K = 50.8 mL. Volume increases because gas particles have greater kinetic energy at higher temperature and occupy more volume at constant pressure.

39. Primary treatment removes large solids and settleable particles through screening and settling. Secondary treatment uses biological processes to reduce dissolved and suspended organic matter. Filtration removes fine particles that remain after earlier steps. Disinfection reduces disease-causing microorganisms before water is released or reused.

40. The claim is incorrect because acid concentration is not the same as degree of ionization. HCl is a strong acid and ionizes almost completely, producing a high H3O+ concentration. Acetic acid is weak and ionizes only partially, so at the same formal concentration it produces less H3O+ and has a higher pH than HCl.

## Final Study Advice

- Redo all mole and solution calculations with units written at every step.
- Memorize common solubility exceptions, especially compounds of Ag+, Pb2+, Ba2+, carbonate, phosphate, and hydroxide.
- For net ionic equations, always write states first, split strong aqueous electrolytes into ions, then cancel spectators.
- For acid-base questions, separate concentration from strength.
- For gas laws, convert Celsius to kelvin before using temperature in a formula.
