# Data folders

- `input/<subject>/`: add your own PDF, DOCX, or image source papers locally. Input files are ignored by Git.
- `blueprints/<subject>/`: reusable blueprint JSON files.
- `generated_tests/<subject>/`: student and teacher outputs.
- `memory/`: local retrieval records.

The shared repository includes reviewed blueprints and generated outputs. It does not commit input papers or the source-material folder.
